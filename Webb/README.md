# Arcade Haven

A modern web-based arcade gaming platform with a beautiful dark mode purple theme. Play classic arcade games directly in your browser!

## Features

- **Beautiful Dark Mode UI**: Enjoy a sleek, eye-friendly dark interface with a breathing purple theme
- **Multiple Classic Games**: Play various arcade games including:
  - Tetris
  - Pacman
  - 2048
  - Tic Tac Toe (against AI)
  - Super Mario
  - Flappy Bird
  - Snake
  - Breakout
- **Responsive Design**: Play on any device - desktop, tablet, or mobile
- **No Installation Required**: Games run directly in your browser
- **Touch Controls**: Mobile-friendly controls for touch devices

## Getting Started

1. Clone this repository or download the files
2. Open `index.html` in your web browser
3. Click on any game card to start playing

## Game Controls

### Tetris
- Arrow Left/Right: Move piece
- Arrow Up: Rotate piece
- Arrow Down: Soft drop
- Space: Hard drop
- P: Pause game

### 2048
- Arrow Keys: Slide tiles
- R: Restart game

### Other Games
Each game displays its controls in the game interface.
